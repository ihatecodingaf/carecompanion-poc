What's real

  • The full app code: the same patient and doctor PWAs that run against Supabase in production.
  • The data model: sample data comes from the project's own SQL migrations and seed, loaded into Postgres and exported.
  • On-device face detection: BlazeFace + MediaPipe 468-point mesh for framing and quality scoring.
  • The check-in logic: status, alerts and Aisha's messages follow the edge function's rules.

What's simulated in this demo

  • The backend runs inside your browser instead of Supabase, so there's nothing to sign up for.
  • AI analysis uses the app's built-in demo mode. In pilot mode the same call goes to Claude Vision.
  • Your photos never leave your browser. A small thumbnail is saved locally; Reset wipes everything.
  • Prescription OCR falls back to a sample prescription.
